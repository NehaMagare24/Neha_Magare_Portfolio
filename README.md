# Neha Liladhar Magare — Portfolio

Animated, responsive static portfolio (HTML / CSS / JavaScript — no build step) with light and dark themes.

## Run locally
Open `index.html` in a browser, or serve the folder:

    npx serve .

## Edit links
All GitHub / LinkedIn / project-repo links live in `site.config.js`. Leave a value as `""` to hide that button.

## Deploy on Vercel
Import the repo at vercel.com -> Framework Preset **Other** -> leave build and output settings empty -> Deploy.

## Structure
- `index.html` — page content
- `style.css` — styling and themes
- `script.js` — animations, theme toggle, profile popup
- `site.config.js` — your links
- `assets/` — photo and resume PDF
